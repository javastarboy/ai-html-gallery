## 检查清单使用说明

### 开发阶段

1. **每日开始前**：检查前一天的任务
2. **每日结束后**：更新完成的任务
3. **每周结束**：整体检查一遍

### 提测前

1. 完整检查所有阶段
2. 标记未完成项
3. 优先解决 P0 问题
4. 记录已知问题

### 部署前

1. 确认所有 P0 和 P1 完成
2. 确认无严重问题
3. 性能测试通过
4. 可访问性检查通过

### 上线后

1. 监控用户反馈
2. 记录问题
3. 制定优化计划
4. 持续迭代
